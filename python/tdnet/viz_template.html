Bit-to-bit prediction map

The agent (triangle) sits at the centre facing up. When it moves, the map slides or turns into the new frame (the true outcome of the action, so a blocked move does not shift anything) while the old predictions fade into the new ones. Every question the TD network asks is an action sequence ending in a sensor bit; resolved through the true outcomes of those actions it names one wall segment. Each segment is drawn with the network's predicted probability of a wall as its darkness, over the true walls in grey. Several questions can land on the same segment: its thickness is how many, and an orange dot marks disagreement.
