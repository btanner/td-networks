The agent (triangle) sits at the centre facing up. Every question the TD network asks is an action sequence ending in a sensor bit; resolved through the true outcomes of those actions it names one wall segment. Each segment is drawn with the network's predicted probability of a wall as its darkness, over the true walls in grey. Several questions can land on the same segment: its thickness is how many, and an orange dot marks disagreement.
